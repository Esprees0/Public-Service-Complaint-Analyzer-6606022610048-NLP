# 📢 Public Service Complaint Analyzer

ระบบวิเคราะห์ข้อความร้องเรียนบริการสาธารณะภาษาไทย

## 📌 แนวคิดของระบบ

ระบบนี้พัฒนาขึ้นเพื่อช่วยวิเคราะห์ข้อความร้องเรียนของประชาชน
โดยรับข้อความภาษาไทยจากผู้ใช้งาน แล้วประมวลผลด้วยเทคนิค NLP
เพื่อสกัดข้อมูลที่สำคัญและช่วยจัดลำดับความสำคัญของปัญหา

ระบบสามารถวิเคราะห์ข้อมูลดังต่อไปนี้

- ประเภทของปัญหา
- สถานที่ที่เกิดปัญหา
- ระดับความเร่งด่วน
- เบอร์โทรศัพท์
- การตัดคำภาษาไทย
- การทำความสะอาดข้อมูลส่วนบุคคล

## 🧠 เทคนิค NLP ที่ใช้

### 1. Regex & Cleansing

ใช้ Regular Expression สำหรับตรวจหาและซ่อนข้อมูลส่วนบุคคล เช่น

- เบอร์โทรศัพท์
- Email
- URL

ตัวอย่าง

ก่อนประมวลผล:

> ติดต่อ 0812345678

หลังประมวลผล:

> ติดต่อ [PHONE]

### 2. Tokenization

ใช้ PyThaiNLP ในการตัดคำภาษาไทย

ตัวอย่าง:

> ไฟถนนหน้ามหาวิทยาลัยเสีย

ผลลัพธ์:

> ไฟ | ถนน | หน้า | มหาวิทยาลัย | เสีย

### 3. Topic Identification

จำแนกประเภทปัญหาจาก Keyword

ประเภทที่รองรับ:

- ไฟฟ้าสาธารณะ
- ถนนและการจราจร
- น้ำประปา
- ขยะและสิ่งแวดล้อม
- ความปลอดภัย
- อื่น ๆ

### 4. Information Extraction

สกัดข้อมูลสำคัญ เช่น

- สถานที่
- เบอร์โทรศัพท์

### 5. Urgency Classification

จำแนกระดับความเร่งด่วนเป็น

- สูง
- ปานกลาง
- ต่ำ

## 🖥️ วิธีใช้งาน

1. เปิดหน้า Web Application
2. กรอกข้อความร้องเรียน
3. กดปุ่ม "วิเคราะห์ข้อความ"
4. ระบบจะแสดงผลการวิเคราะห์

## 🤖 ตัวอย่าง Prompt ที่ใช้ AI ช่วยพัฒนา

ตัวอย่าง Prompt:

> ช่วยออกแบบ Web Application ด้วย Streamlit
> สำหรับวิเคราะห์ข้อความร้องเรียนบริการสาธารณะภาษาไทย
> โดยใช้ Regex สำหรับลบข้อมูลส่วนบุคคล
> ใช้ PyThaiNLP สำหรับ Tokenization
> และใช้ Keyword Matching สำหรับจำแนกประเภทปัญหา
> และระดับความเร่งด่วน

อีกตัวอย่าง:

> ช่วยเขียน Python Function สำหรับตรวจหาเบอร์โทรศัพท์
> Email และ URL ในข้อความภาษาไทยด้วย Regular Expression
> และแทนที่ข้อมูลเหล่านี้ด้วย [PHONE], [EMAIL] และ [URL]
